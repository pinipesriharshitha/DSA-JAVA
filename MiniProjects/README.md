# Student Marks Management System

## About the Project
This is a beginner-level Java project built to practice array operations and basic programming logic.

## Features
- Store student marks
- Display marks
- Calculate total and average
- Find the highest and lowest marks

*Note: Include only the features implemented in your code.*

## Concepts Used
- Java basics
- Arrays
- Loops
- Conditional statements
- Basic calculations

## How to Run
1. Install Java JDK.
2. Save the source file as `Main.java`.
3. Compile using `javac Main.java`.
4. Run using `java Main`.

## What I Learned
I practiced using arrays to store and process data, applying loops and conditions, and organizing a small Java project.
